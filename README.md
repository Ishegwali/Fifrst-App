# TaskPulse - Todo App Dashboard

A simple to-do list app that helps you track your tasks. It looks like a modern dashboard and runs entirely in your browser.

## What it does

- Add, edit, and delete tasks
- Mark tasks as done with a checkbox
- Break tasks into smaller checklist items (subtasks)
- Sort tasks into categories: Work, Personal, Coding, Health, Finance
- Set priority levels: High, Medium, Low
- Set a due date for each task (overdue and today's tasks are highlighted)
- Search tasks by title or description
- Filter by category or priority
- Sort by due date, priority, created date, or alphabet
- Switch between grid view and list view
- See live stats: total tasks, pending, completed, and a productivity score
- Clear all completed tasks in one click
- Reset back to the demo tasks at any time

Your tasks are saved in your browser's local storage, so they are still there after you close and reopen the page.

## Files

| File | What it is |
|------|-----------|
| `index.html` | The page structure |
| `style.css` | The dark theme and layout |
| `app.js` | All the app logic and saving/loading |

## How to run it

No setup or install needed.

1. Download or clone this folder
2. Open `index.html` in any web browser
3. Start adding tasks

That's it.

## Requirements

Works in any modern browser (Chrome, Firefox, Edge, Safari). No internet connection is needed, except for loading the font.

## Tech used

Plain HTML, CSS, and JavaScript. No frameworks, no libraries, no build tools.

## Resetting the demo

Click **Reset Demo Data** at the bottom of the sidebar to restore the original sample tasks. This will replace whatever tasks you have.
